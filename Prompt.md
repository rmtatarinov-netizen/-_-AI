Создай Telegram-бота на Python с использованием библиотеки pyTelegramBotApi.

🔹 Основные требования:

Бот подключается к ProxyAPI (модель gpt-5-mini-2025-08-07).
Каждый пользователь должен иметь свой контекст диалога (бот должен помнить последние сообщения).
Контекст хранить в памяти (dict) или в файле/SQLite — выбери самый простой вариант (dict в оперативной памяти).
После каждого ответа бота — контекст обновляется.
Если пользователь пишет "очистить контекст" — контекст для этого пользователя очищается.
Весь код оформить в файлы:
bot.py — основной файл
config.py — хранение токенов и настроек
openai_client.py — функция общения с OpenAI
context_manager.py — сохранение и загрузка контекста пользователя
🔹 Что использовать:

pyTelegramBotApi 4.14.0
openai (официальная библиотека)
Python 3.10+
.env файл для токенов
🔹 Пример .env:

BOT_TOKEN=твой_тг_токен

PROXYAPI_API_KEY=твой_ключ

🔹 Пример логики для отправки запроса:

messages = context[user_id] + [{"role": "user", "content": text}]

response = openai.ChatCompletion.create(

model="gpt-5-mini-2025-08-07",

messages=messages,

)
